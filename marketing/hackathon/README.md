# hermes-otel — hackathon demo film

An ~84 s narrated film for the [Hermes Agent Plugin Hackathon](https://nousresearch.com)
(Nous Research; demo must be under 90 s, posted on X tagging @NousResearch). Built with
[HyperFrames](https://hyperframes.heygen.com). Storyline "The Tracks": Hermes stole Apollo's cattle
and walked them backwards so nobody could follow; hermes-otel makes every Hermes turn leave a trace.

```
marketing/hackathon/
  STORYLINES.md     the three pitched films and why A was picked
  SPEC.md           the director's brief: palette, type, motion and every shot, in numbers
  SCRIPT.md         the narration — edit this to change what is said
  cues.json         per-scene voice timings (written by synth_voice.py; source for build.py)
  cues.words.json   word timestamps (Whisper) used to land cuts on spoken words
  timeline.json     the laid-out film: scene starts, anchors, picture events
  index.html        GENERATED root composition (from tools/index.template.html)
  compositions/     one hand-written scene per file; only their /*CUES*/ line is generated
  tools/
    prep_assets.py    stages every binary into assets/ (fonts, art, shots, clips, sfx)
    synth_voice.py    narration → assets/voice/*.wav + cues.json (kokoro | magpie | openai-compatible)
    pronounce.json    spoken spellings ("Hermes O-tel", "O.T.L.P.", "Yayger", ...)
    gen_music.py      placeholder bed with local MusicGen → assets/bgm/bed.wav
    build.py          lays out scenes from the voice, writes index.html + every CUES line + the SFX
```

Nothing binary is committed (`.gitignore`): fonts, art, screenshots, terminal clips, voice, music,
effects and renders are all regenerated by the tools.

## Sources (all real)

- Screens: the captures committed under `marketing/tour/assets/shots/` (Hermes dashboard tab and
  seven backends' own UIs, from one scripted workload). Every number on screen is read off them.
- Terminal: `marketing/terminal/renders/span-tree.mp4` (the observability skill drawing a turn).
- Fonts and palette: Hermes Agent's own dashboard (Nous design-system fonts in
  `hermes-agent/web/public/fonts`, the Hermes Teal theme) and the hermes-agent site tokens
  (`#0000f2`, `#f2f2f2`).
- Art: Hendrick Goltzius after Polidoro da Caravaggio, *Mercury*, c. 1592, National Gallery of Art
  (CC0), as two duotone plates.
- Effects: HyperFrames' bundled CC0 SFX library.

## Rebuild

```bash
cd marketing/hackathon
uv run --with pillow python tools/prep_assets.py              # needs ~/git/hermes-agent and marketing/terminal renders

# narration: local Kokoro now; swap provider when the k3s services are reachable
HYPERFRAMES_PYTHON=/path/to/venv-with-kokoro-onnx/bin/python python3 tools/synth_voice.py
#   python3 tools/synth_voice.py --provider magpie --url https://magpie.lan
#   TTS_API_KEY=... python3 tools/synth_voice.py --provider openai --url https://<inference host> --model <m> --voice <v>

uv run --with torch --with transformers --with soundfile --with numpy python tools/gen_music.py   # or drop a track at assets/bgm/bed.wav
python3 tools/build.py                                        # prints each scene's slot and the total (must stay < 89.9 s)

npx hyperframes@0.9.14 check
npx hyperframes@0.9.14 preview
npx hyperframes@0.9.14 render --quality high --output renders/hermes-otel-hackathon.mp4
```

Editing the narration: change a line in `SCRIPT.md`, re-run `synth_voice.py` (only changed sentences
are synthesised) and `build.py`. Scene lengths, word-anchored cuts and sound effects all move with
the voice. If a changed sentence drops an anchor word, `build.py` reports `anchors=n/m`; update
`ANCHORS` in `tools/build.py`.
