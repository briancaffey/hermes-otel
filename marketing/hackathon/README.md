# hermes-otel — hackathon demo film

A sub-90 s narrated film for the [Hermes Agent Plugin Hackathon](https://nousresearch.com)
(Nous Research; demo must be under 90 s, posted on X tagging @NousResearch). Built with
[HyperFrames](https://hyperframes.heygen.com). Storyline "The Tracks": Hermes stole Apollo's cattle
and walked them backwards so nobody could follow; hermes-otel makes every Hermes turn leave a trace,
read through OpenTelemetry's telescope.

Draft 3 (2026-11-08): 11 scenes. The myth, the black box, why OpenTelemetry, one turn = one trace,
local SQLite + the dashboard tab, the tab reading any backend, any OTLP backend with async fan-out
(rapid cuts of every backend UI + the wall), GenAI + OpenInference conventions, Claude Code metric
names, Hermes reading its own trace, the close.

```
marketing/hackathon/
  SCRIPT.md         the narration — edit this to change what is said (fact notes at the top)
  media.json        every generated asset: prompt, seed, references (art, 3D, clips, music)
  cues.json         per-scene voice: duration, sentence windows, ASR word timings (written by narrate.py)
  timeline.json     the laid-out film (written by build.py)
  index.html        GENERATED root composition (from tools/index.template.html)
  compositions/     one hand-written scene per file (s01–s11); only their /*CUES*/ line is generated
  tools/
    prep_assets.py    stages fonts, the Goltzius plate, every captured screenshot, terminal clips,
                      quiet SFX and the backend logos into assets/
    gen_media.py      renders media.json on club.lan (inference.club): FLUX 3 klein engravings and
                      style transfers, TRELLIS-2 meshes, LTX-2.5 clips, ACE-Step music
    narrate.py        narrates SCRIPT.md on club.lan's Narration Studio and exports the clips
    narration_state.json  the club.lan episode / voice-sample ids narrate.py reuses
    build.py          lays the film out from the voice, writes index.html + every CUES line + the SFX
```

Nothing binary is committed: fonts, art, screenshots, logos, voice, music, effects and renders are
regenerated by the tools.

## Where everything comes from

- **Voice**: Dia 1.6B cloning one designed narrator ("Hermes OTel Narrator", voice sample 1 on
  club.lan, chosen from 6 auditioned seeds by ASR grade and pace), every take cleaned by NVIDIA Maxine
  StudioVoice (running on the `blade` node), transcribed by Nemotron ASR, trimmed (word timings +
  waveform silence), levelled to −16 LUFS and graded; autopilot retakes a line until it passes.
  Spoken spellings live in `LEXICON` in `tools/narrate.py`.
- **Art**: engravings generated on club.lan with FLUX 3 klein using the CC0 Goltzius *Mercurius* (1592,
  NGA) as the style reference; `x01-waterfall` is a style transfer of a real dashboard capture.
- **Music**: one ACE-Step 1.5 track (`bgm-a`, 100 bpm), normalised to −16 LUFS. Effects: only quiet
  clicks, keys and short whooshes from HyperFrames' bundled CC0 library.
- **Screens**: real captures from one scripted workload (`marketing/tour/assets/shots/<backend>-local/`):
  `ui-*` are each backend's own UI, the rest are the plugin's dashboard tab reading that backend.
  Claude Code dashboards: `website/static/img/`. Every number on screen is read off a capture.
- **Logos**: simple-icons (coloured with the brand colour) or the project's GitHub org avatar;
  marks belong to their owners and appear only next to the backend's name.

## Rebuild

```bash
cd marketing/hackathon
uv run --with pillow python tools/prep_assets.py      # needs ~/git/hermes-agent and marketing/terminal renders
python3 tools/gen_media.py                            # club.lan token in ~/.config/inference-club/club-lan.token
ffmpeg -i assets/gen/bgm-a.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 assets/bgm/bed.wav
python3 tools/narrate.py                              # first run: --design auditions and saves the narrator voice
python3 tools/build.py                                # prints each scene's slot and the total (must stay < 89.9 s)

npx hyperframes@0.9.14 check
npx hyperframes@0.9.14 preview
npx hyperframes@0.9.14 render --quality high --output renders/hermes-otel-hackathon.mp4
```

Editing the narration: change a line in `SCRIPT.md`, re-run `narrate.py` (only scenes whose text
changed are re-voiced: the site sends an edited segment back to pending) and `build.py`. Cuts land on
spoken words through each scene's `at(/regex/)` lookups on the ASR word timings; scene lengths and
sound effects move with the voice. `narrate.py --reprocess` re-cleans/re-trims the current takes,
`--redo S03` forces a new take for a scene. You can also edit takes by hand in the Studio
(club.lan → Media → Studio → "Hermes OTel — hackathon film") and re-run `narrate.py --export-only`.
